### **1. الواجهة الرئيسية (Main UI)**

تم تصميم الواجهة بأسلوب عصري يعتمد على النمط الداكن (Dark Mode) وتتكون من الأجزاء التالية:

* **شريط العنوان العلوي:**
* يضم أيقونة البرنامج واسمه **TAGS**.


* **شريط البحث (Search your clipboard...):** للبحث السريع عن أي عنصر أو نص قديم تم نسخه سابقاً داخل الحافظة.


* **فلتر العلامات (IMPORTANT):** زر لتصفية العناصر بناءً على العلامات أو الوسوم المهمة.


* **أزرار التحكم العلوية:** زر لإنشاء علامة جديدة (`+ New tag`)، زر الإعدادات، زر السجل، وأزرار إغلاق أو تصغير النافذة.




* **القائمة الجانبية (Sidebar):**
* **All items:** تعرض إجمالي عدد العناصر المحفوظة (مثال: 17 عنصراً).


* **Text:** لتصفية وعرض النصوص فقط (مثال: 7 عناصر).


* **Images:** لتصفية وعرض الصور المحفوظة (مثال: 0 عناصر).


* **Files:** لتصفية وعرض الملفات المنسوخة (مثال: 10 عناصر).


* **Pinned:** لتصفية العناصر المثبتة التي لا تنتهي صلاحيتها (مثال: عنصراً واحداً).




* **منطقة عرض البطاقات (Cards Grid):**
* تعرض المحتويات على هيئة بطاقات أفقية أو عمودية (مثل الروابط، النصوص، أو الملفات التنفيذية مثل `.exe` و `.rar`).


* تحتوي كل بطاقة على تفاصيل توضيحية: مثل التطبيق الذي تم النسخ منه (مثل Explorer أو Freebuff أو Unknown app)، الوقت المنقضي على النسخ (مثل `5m ago` أو `2h ago`)، حجم المحتوى (مثل `98 chars` أو `1 file`)، وزر تصنيف أو وسم (مثل `IMPORTANT` أو نوع المحتوى `TEXT` / `FILE`).

### **2. شاشة الإعدادات (Settings)**

تتيح لك هذه الشاشة تخصيص سلوك البرنامج بالكامل ليناسب احتياجاتك، وتتضمن الأقسام التالية:

* **الاختصار العام (Global shortcut):**
* يتيح لك فتح البرنامج من أي مكان بالنظام باستخدام اختصار لوحة مفاتيح مخصص (الافتراضي الظاهر هو `Shift + Z`)، مع إمكانية النقر والضغط على أي مجموعة مفاتيح تفضلها.




* **حجم السجل (History size):**
* خانة لإدخال الحد الأقصى لعدد العناصر التي يحتفظ بها البرنامج (محدد في الصورة بـ `5700` عنصر)، مع ملاحظة أن العناصر المثبتة (Pinned) لا تنتهي صلاحيتها أبداً ولا يتم حذفها تلقائياً.




* **خيارات التشغيل:**
* **Start TAGS when Windows starts:** خيار لتشغيل البرنامج تلقائياً مع بدء نظام التشغيل.


* **Pause clipboard capture:** خيار لإيقاف التقاط وحفظ النسخ مؤقتاً.




* **تطبيقات المستبعدة للخصوصية (Never capture from these apps):**
* صندوق نصي لكتابة أسماء العمليات أو التطبيقات التي لا يريد المستخدم حفظ أي شيء يتم نسخه منها (عملية واحدة في كل سطر)، مثل برامج إدارة الكلمات المرورية الحساسة المذكورة افتراضياً: `keepass`، `keepassxc`، `1password`، `bitwarden`، و `lastpass`.




* **اختصارات لوحة المفاتيح (Keyboard shortcuts):**
يوفر البرنامج اختصارات سريعة للتحكم الكامل بلوحة المفاتيح دون استخدام الفأرة:
* **Copy item:** `Ctrl + C` (نسخ العنصر).


* **Cut item:** `Ctrl + X` (قص العنصر).


* **Copy without pasting:** `Ctrl + Enter` (نسخ العنصر للحافظة دون لصقه مباشرة).


* **Search:** `Ctrl + F` (الفتح المباشر للبحث).


* **Close window:** `Esc` (إغلاق نافذة البرنامج).


* **Paste item:** `Ctrl + V` (لصق العنصر).


* **Paste #1 ... #9:** `Ctrl + 1 ... 9` (لصق أول 9 عناصر مسجلة بسرعة).


* **Pin / unpin:** `Ctrl + P` (تثبيت أو إلغاء تثبيت عنصر).


* **New tag:** `Ctrl + T` (إنشاء علامة/وسم جديد).


* **Settings:** `Ctrl + ,` (فتح إعدادات البرنامج).




* **أزرار التحكم السفلى في الإعدادات:**
* **Open data folder:** لفتح مجلد البيانات الخاص بالبرنامج على جهازك.


* **Clear history...:** لمسح سجل الحافظة بالكامل.


* **Cancel:** إلغاء التغييرات والخروج من الإعدادات.


* **Save:** حفظ التعديلات الجديدة.


* **معلومات المطور:** يظهر في الأسفل اسم مطور البرنامج (Developer Manager: Andrew Zaki).
